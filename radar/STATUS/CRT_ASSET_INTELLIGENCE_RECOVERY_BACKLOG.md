# CRT Asset Intelligence Recovery Backlog（CRT 資產智慧恢復清單）

## 定位

本檔是 CRT（前行者研究院）已完成或已形成重要研究成果的資產智慧恢復清單。

目的不是重新研究，而是防止過去已完成的成果只存在聊天室、歷史對話或孤立檔案中，最後無法進入 Live Action Loop（實戰行動迴路）。

本清單不是新的正式模型，也不是 Phase / Wave / Work Order / Dashboard（階段／波次／工單／儀表板）。

## 啟動規則

- `TOTAL = 5`
- `DONE = 0`
- `ACTIVE = NONE`
- `PROGRESS = 0%`
- `START_AFTER = CRT_LIVE_ACTION_LOOP_8_OF_8`
- 完成率只使用：`DONE / 5`
- 在 CRT Live Action Loop（實戰行動迴路）達成 `8 / 8` 前，本清單保持 `DORMANT`（待命）。
- 除非使用者明確批准，或某項被證明直接阻塞目前 8 項主線，否則不得提前施工。
- 本清單不得增加或重定義 `radar/STATUS/CRT_ACTIVE_BATON.md` 的 8 項分母。

## 共用恢復原則

每項資產智慧恢復均遵循：

`Past Finding（過去成果）`
→ `Source Verification（來源驗真）`
→ `Machine-Readable Facts（機器可讀事實）`
→ `Deterministic Calculation（確定性計算）`
→ `Evidence Pack（證據包）`
→ `Asset-Specific Context（資產專屬脈絡）`
→ `GPT Judgment（GPT 判斷）`
→ `User Decision（使用者決策）`

共同規則：

1. 優先救回既有成果，不重新發明。
2. 歷史數字、價格、APR（年化配息率）、mNAV（資產淨值倍數）與公司狀態重新使用前必須驗真。
3. 聊天紀錄可以作 Recovery Evidence（恢復證據），不能直接升格為正式市場事實。
4. 不因恢復工作自行修改六層權重、燈號閾值、mNAV 語義、Production approval（正式生產批准）或 External Action Authority（外部行動權限）。
5. 未加限定的 `mNAV` 永遠維持 `Diluted Equity mNAV`（稀釋股權資產淨值倍數）。
6. 機器負責蒐集、驗真、計算與比較；GPT（大廚）負責理解、推理與決策建議；使用者保有最終資本決定權。
7. 不得因恢復完成而建立自動交易權限。
